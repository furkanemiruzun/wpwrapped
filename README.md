# ChatWrapp

A premium WhatsApp Chat Analyzer and Visualizer.
Built with React, Vite, TailwindCSS, and Framer Motion.

## Features
- 🔒 **100% Private**: Processing happens in your browser.
- 📊 **Deep Analysis**: Statistics on users, words, emojis, and activity times.
- 🎨 **Premium UI**: Glassmorphism design with smooth animations.
- 📱 **Responsive**: Works on desktop and mobile.

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to the URL shown (usually `http://localhost:5173`).

## Usage
1. Export your WhatsApp chat (Settings > Chats > Export Chat > Select Chat > Without Media).
2. Save the `_chat.txt` file.
3. Drop the file into the ChatWrapp interface.
